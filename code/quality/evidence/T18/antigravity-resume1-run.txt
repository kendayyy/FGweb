#### 2. Implementation Summary
1. **Room REST Endpoints & Contracts:**
   - `POST /api/v1/rooms`: Creates persistent room, `ROOM` conversation, sets `OWNER` role in `room_members` and inserts owner into `conversation_members` inside an isolated transaction. Validates `gameId`/`gameTitle`.
   - `GET /api/v1/rooms` & `GET /api/v1/rooms/own`: Paginated list of member rooms with database ISO timestamp cursor precision (`to_char(r.created_at AT TIME ZONE 'UTC', 'YYYY-MM-DD"T"HH24:MI:SS.US"Z"')`), `null` `nextCursor` when page is exhausted, and 422 validation on malformed cursors.
   - `GET /api/v1/rooms/:id` & `GET /api/v1/rooms/:id/members`: Enforces room membership check inside transaction. Outsiders receive `403 FORBIDDEN`. Returns projected `UserSummary` (`id`, `displayName`, `avatarUrl`, `customStatus`).
   - `PATCH /api/v1/rooms/:id/settings`: Restricted to owner. Atomically updates settings and executes SQL predicate `UPDATE recruitments SET state = 'CLOSED' WHERE room_id = $1 AND state = 'OPEN'` when visibility transitions to `PRIVATE`.
   - `PATCH /api/v1/rooms/:id/helpers/:userId`: Owner-only. Validates helper permissions (rejects `OWNER_TRANSFER`/`ROOM_DISSOLVE` with 422). De-duplicates input permissions. **Deletes `permission_grants` BEFORE modifying `room_members.role`** to satisfy immediate FK constraints.
   - `POST /api/v1/rooms/:id/transfer-owner`: Owner-only. Rejects non-member outsiders (`403 FORBIDDEN`). Atomically transfers ownership inside transaction with row locks, clearing previous helper grants.
   - `DELETE /api/v1/rooms/:id/members/:userId`:
     - Self-leaving: Prevents owner from leaving when other members exist (`403 FORBIDDEN`); dissolves room when sole member owner leaves. Revokes `conversation_members` chat access.
     - Member removal: Enforces `MANAGE_MEMBERS` permission for helpers, prevents helpers from kicking helpers/owner.
   - `DELETE /api/v1/rooms/:id`: Owner-only room dissolution. Cascades deletion of room, memberships, permission grants, and room conversation.
