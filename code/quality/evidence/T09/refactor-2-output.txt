### 2. Behavioral Enhancements
1. **Redirect Security**: Rejects all external domain open-redirects, protocol-relative paths (`//evil.com`), backslash tricks (`/\\evil.com`), newline/tab injections, and `javascript:` URIs.
2. **OAuth Authorization Validation**: `signInWithDiscord` strictly checks the returned URL structure before redirection.
3. **Logout & Cache Invalidation**: Server sign-out failure rejects promises and displays a `role="alert"` UI banner with a working `"Thử lại"` button. Successful logout clears query caches and runs registered Socket/Call cleanups.
4. **Accessible Error & Retry UI**: `<HeaderAuthWidget />` and `<ProtectedRoute />` expose accessible `role="alert"` regions with retry buttons.
5. **Touch Target & Layout Integrity**: All button controls guarantee `minHeight: 44px`. Verified no horizontal scrollbar overflow across 1440x900, 1280x800, 390x844, and 360x800 viewports.
