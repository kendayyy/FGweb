### Summary of Work Done for T17-FE

1. **Per-Conversation Caching, History Error Recovery & Bounded Socket Subscriptions (`useDirectMessages.ts`)**
   - **Per-Conversation Cache**: Implemented `cacheRef` keyed by `actorId:conversationId` to retain message history and pagination state when switching between direct conversations. Switching back to a previously opened conversation immediately displays cached history without clearing or unnecessary refetching. Actor transitions clear the owned private cache map.
   - **History Error & Retry**: Added `messagesError` state and `refetchMessages` callback so history loading errors are exposed explicitly rather than turned into empty success states.
   - **Bounded Socket ACK & Reconnect Recovery**: Wrapped socket conversation subscription ACK (`emitWithAck`) with a 5000ms race timeout, and added automatic history refetching on socket `connect`/`reconnect` to recover any missed live messages.
   - **Composer Key & Reply Reset**: Updated composer key to `${user.id}-${dm.activeConversationId || 'none'}` and added reply quote reset whenever active conversation or actor changes.

2. **Dialog Keyboard Focus Trap & Accessibility (`useDialogFocusTrap.ts`, `FriendsModal.tsx`, `DirectMessagesPanel.tsx`)**
   - Created reusable `useDialogFocusTrap` hook to manage modal keyboard accessibility for `FriendsModal` and `DirectMessagesPanel`.
   - **Focus Acquisition & Trapping**: Automatically shifts focus into the modal upon opening and traps `Tab`/`Shift+Tab` focus cycling strictly within enabled, visible controls inside the modal container.
   - **Escape & Opener Restoration**: Pressing `Escape` closes the modal (and clears active DM in `DirectMessagesPanel`) while restoring focus to the triggering opener element.

3. **Design Tokens & Git Diff Cleanup**
   - Verified semantic design tokens (`--bg-panel`, `--bg-sidebar`, `--navy-raised`, `--border-default`, `--text-primary`, `--text-secondary`, `--text-muted`, `--blue-action`, `--red-destructive`, `--green-status`).
   - Ensured `<= 640px` single-column mobile layouts and `>= 44px` minimum touch target areas on interactive controls.
   - Removed extra EOF trailing blank lines in `LobbyPage.tsx` and `ProfilePage.tsx` (`git diff --check` passes cleanly).

4. **Relationship & List Truthfulness (`FriendsModal.tsx`, `PeerSocialControls.tsx`)**
   - Added explicit query error states with "Thử lại" (Retry) buttons for Friends, Friend Requests, and Block list queries instead of silently assuming empty lists.
   - Added "Tải thêm" (Load More) pagination support for Friends and Friend Requests lists when `hasMore` is true.

### Final Refactor Summary for T17-FE

#### 1. Per-Conversation Caching, History Errors & Socket ACK Timeout (`useDirectMessages.ts`)
- **Per-Conversation Cache**: Maintained `cacheRef` keyed by `${actorId}:${conversationId}`. Switching between direct conversations retains cached messages and cursor states without re-clearing or duplicate refetching. Switching actors clears the owned private cache map.
- **Explicit History Load Errors**: Added `messagesError` state and exported `refetchMessages` callback to allow callers to display error banners and trigger manual retries.
- **Bounded ACK & Reconnection Recovery**: Added a 5000ms timeout race to `socket.emitWithAck` for conversation subscriptions and automatic history refetch on socket `connect`/`reconnect` to recover any missed live messages.
- **Composer Key & Reply Reset**: Updated `RichComposer` key to `${user.id}-${dm.activeConversationId || 'none'}` and reset reply state whenever conversation or actor changes.

#### 2. Keyboard Navigation & Focus Trap (`useDialogFocusTrap.ts`, `FriendsModal.tsx`, `DirectMessagesPanel.tsx`)
- **Focus Acquisition & Trapping**: Created `useDialogFocusTrap` to acquire focus inside `FriendsModal` and `DirectMessagesPanel` when opened, trapping `Tab`/`Shift+Tab` focus cycling deterministically within enabled, visible modal controls (excluding sr-only file inputs).
- **Opener Focus Restoration & Escape Handling**: Pressing `Escape` closes the modal (clearing active DM in `DirectMessagesPanel`) and restores focus back to the triggering opener element (such as `btn-open-dm` or `btn-friends`).

#### 3. Design Tokens & Git Diff Cleanup (`LobbyPage.tsx`, `ProfilePage.tsx`)
- Standardized UI colors and borders to use theme tokens (`--bg-panel`, `--bg-sidebar`, `--navy-raised`, `--border-default`, `--text-primary`, `--text-secondary`, `--text-muted`, `--blue-action`, `--red-destructive`, `--green-status`).
- Removed trailing EOF blank lines in `LobbyPage.tsx` and `ProfilePage.tsx` (`git diff --check` passes cleanly).

#### 4. Relationship & List Truthfulness (`FriendsModal.tsx`, `PeerSocialControls.tsx`)
- **Error Handling & Retry**: Friends, Friend Requests, and Block list queries in `FriendsModal` display explicit error states with "Thử lại" (Retry) buttons rather than assuming empty lists.
- **Pagination**: Added "Tải thêm" (Load More) pagination support in `FriendsModal` for Friends and Friend Requests lists when `hasMore` is true.
