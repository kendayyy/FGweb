### 4. Ranh giới & Giới hạn công việc (Boundaries & Limitations)

- Ràng buộc tầng Database đảm bảo seat atomic, giới hạn 10 người/call, max 3 publisher, unique active call/user, webhook anti-replay, dedup notifications/outbox, và lịch sử audit khi target bị xóa (`ON DELETE SET NULL`).
- **Giới hạn**: Ràng buộc DB không thay thế cho LiveKit SFU media routing, WebRTC bandwidth adaptation, Push/Email Worker delivery hay API Authorization endpoints (thuộc các task từ T08 trở đi).
- Không tự động sửa ledger `tasks.json` (do script task:check quản lý). Khóa preflight gate PASS tại `quality/evidence/T07/preflight-gate.txt` sẵn sàng cho Codex review độc lập trước khi mở khóa T08.
