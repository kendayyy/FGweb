### Key Invariant Fixes Applied

1. **Room Owner Role Requirement**:
   - Added `owner_role` column (default `'OWNER'`, CHECK `owner_role = 'OWNER'`) to `rooms` and composite foreign key `rooms_owner_membership_fk` targeting `room_members(room_id, user_id, role)`.
   - Added partial unique index `room_members_one_owner_per_room_idx` on `room_members(room_id) WHERE role = 'OWNER'` to enforce exactly 1 owner per room.
   - Attempts to assign room owner to a member without `OWNER` role now fail with PostgreSQL error `23503`.

2. **Non-Cascading Owner Membership FK**:
   - Updated `rooms_owner_membership_fk` from `ON DELETE CASCADE` to `ON DELETE NO ACTION DEFERRABLE INITIALLY DEFERRED`.
   - Deleting an owner's membership without transferring ownership within a transaction is rejected with PostgreSQL error `23503`, preserving rooms and play history.

3. **Room Chat Uniqueness & Privacy Boundary**:
   - Added `rooms_conversation_id_unique` constraint on `rooms(conversation_id)`.
   - Attempting to link a second room to an existing chat conversation fails with PostgreSQL error `23505`.

4. **Helper Permission Grantee Role Boundary**:
   - Added `grantee_role` column (default `'HELPER'`, CHECK `grantee_role = 'HELPER'`) to `permission_grants` and composite foreign key `permission_grants_member_fk` targeting `room_members(room_id, user_id, role)`.
   - Granting permissions to regular `MEMBER` users fails with PostgreSQL error `23503`, while owner-only permissions fail with `23514`.

5. **Recruitment Room/Game Match, Canonical Title, Session Link & Roblox Checks**:
   - Added `unique('rooms_id_game_unique')` on `rooms(id, game_id)` and composite FK `recruitments_room_game_fk` referencing `rooms(id, game_id)` (error `23503` on mismatch).
   - Added `unique('games_id_title_unique')` on `games(id, title)` in [games.ts](file:///E:/FGweb/code/packages/database/src/schema/games.ts) and composite FK `recruitments_game_title_fk` referencing `games(id, title)`.
   - Added optional `play_session_id` link referencing `play_sessions(id, room_id)`.
   - Updated `recruitment_roblox_fields_check` to require non-empty `experience_name` and `experience_url` for Roblox and forbid them for non-Roblox games.

6. **Play Session Invitation Room Consistency**:
   - Added `unique('play_sessions_id_room_unique')` on `play_sessions(id, room_id)` and composite FK `invitations_session_room_fk` targeting `play_sessions(id, room_id)`.
   - Play session invitations referencing a session from a different room fail with PostgreSQL error `23503`.

7. **Active Play Slot Roster Seat Match**:
   - Added `unique('team_members_session_user_slot_unique')` on `team_members(play_session_id, user_id, slot_index)` and composite FK `active_play_slots_roster_fk` targeting `team_members(play_session_id, user_id, slot_index)`.
   - Active play slot seat entries with negative or mismatched seat numbers fail with PostgreSQL error `23503`.
