### 3. Coalescing Mechanism & Lifecycle Concurrency

1. **Per-Group Ordinary Trigger Coalescing**:
   - Ordinary triggers (`ended === undefined`) are managed via `this.coalescers = new Map<string, GroupRunner>()` scoped strictly per call group `id`.
   - For a fixed concurrent burst arriving while an active pass is running: work is bounded to at most **2 passes** (the in-flight pass + 1 fresh trailing pass).
   - If triggers continue to arrive during the trailing pass, subsequent passes run fresh (no lost wakeups; no false global $\le 2$ claim for indefinite event streams).
   - All callers resolve **after** a pass covering their trigger finishes, or reject with the exact same error if that pass fails.
2. **Screen-Ended Event Preservation**:
   - Webhook `track_unpublished` events deliver `ended: { identity, at }`.
   - Existing `PublishingService.reconcileWithin` accepts only a single `ended` object.
   - **Rule**: Each distinct screen-ended event is queued in `pendingEnded` and runs its own canonical `await this.reconcilePass(id, ended)`. None are batched, dropped, or deduplicated away.
3. **Multi-Group Independence**:
   - Triggers for call group 1 and call group 2 operate on independent runners without cross-group interference. Where groups touch the same room, database row locks serialize safely.
4. **Error Identity & Map Recovery**:
   - If `reconcilePass` fails, all callers in that pass's batch reject with the exact same error instance.
   - Failures do not permanently pin the map; if queues empty, the runner is deleted so subsequent sweeps or retried signed webhooks run fresh. Older `finally` checks `this.coalescers.get(id) === runner` to avoid deleting newer map entries.
5. **Shutdown & Drain (`onModuleDestroy`)**:
   - Sets `this.closing = true`, stops the sweep timer, and awaits `this.running`.
   - Drains all active in-flight passes and queued ended-event jobs (`while (this.inFlight.size > 0) await Promise.allSettled(...)`) before calling `this.pool?.end()`.
   - Requests arriving after shutdown begins reject immediately with 503 (`HttpException: Service shutting down`), preventing unbounded work against a closing pool.
6. **Strict Invariants Preserved**:
   - Lock modes: `SELECT id FROM rooms WHERE id=$1 FOR UPDATE`, `call_groups FOR UPDATE`, and `FOR UPDATE OF m` remain strictly exclusive (no `SHARE` relaxation).
   - Media RPCs remain inside canonical transaction; `requestTimeout: 3`, pool (max 8, 5s timeout, 15s statement timeout), 1000ms sweep interval, and `actor()` / `liveLease()` validations remain unchanged.

### 5. Regression Controls Matrix

| Control | Description | Verification Criterion |
|---|---|---|
| **CTL-01** | Fixed Ordinary Burst Bounded | 4 concurrent ordinary triggers on group 1 execute $\le 2$ native reads (`listRooms`); all 4 callers resolve. |
| **CTL-02** | Multi-Group Independence | Concurrent triggers on group 1 and group 2 run independent passes without cross-suppression ($\ge 2$ total reads). |
| **CTL-03** | No Lost Wakeup During Trailing | Trigger arriving during trailing pass triggers a third fresh pass; all callers resolve. |
| **CTL-04** | Distinct Ended Event Runs | Two distinct screen-ended events each execute their own canonical reconciliation pass ($\ge 2$ passes). |
| **CTL-05** | Error Identity & Recovery | Native SDK failure rejects all concurrent callers with exact error; subsequent call recovers cleanly. |
| **CTL-06** | Signed Duplicate Webhooks | Duplicate signed webhooks both trigger reconciliation cleanly (`receive()` durable insert pipeline intact). |
| **CTL-07** | Shutdown Drain Integrity | `onModuleDestroy` drains in-flight and queued passes cleanly; requests during shutdown rejected without pool errors. |
