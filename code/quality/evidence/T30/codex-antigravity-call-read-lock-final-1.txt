### 1. Codex Review Cleanup & Lint Corrections Applied

- **Early Environment Capture**: `const originalDbUrl = process.env.DATABASE_URL;` is captured immediately at module evaluation.
- **Teardown Safety**: The database schema drop (`DROP SCHEMA ... CASCADE`) runs in an inner `finally` block within `afterAll`, guaranteeing schema teardown is always attempted even if `callsService.onModuleDestroy()` rejects. The outer `finally` block restores `process.env.DATABASE_URL`.
- **Strict Typing & 0 ESLint Errors**:
  - Eliminated loose `any` casts.
  - Substituted typed doubles using `ConstructorParameters<typeof CallsService>`.
  - Typed `readResult` and `originalApiPromise` using contract DTOs (`CallGroupDTO[] | CallParticipantDTO[]`).
  - Error catching uses typed `unknown` narrowed with `instanceof HttpException` guards and `toMatchObject({code: expectedCode, message: expectedMessage})`.
  - Cleaned all 13 ESLint issues (verified exit code 0 in [`codex-t30-call-read-lock-final-patch-lint-2.json`](file:///E:/FGweb/code/quality/evidence/T30/codex-t30-call-read-lock-final-patch-lint-2.json)).
- **CallsService Lock Policy**: Only `list` and `participants` use `'FOR SHARE'`; all mutation paths (`create`, `join`, `leave`, `selfMic`, `withControlGroup`, `sessionDeleted`) strictly retain default exclusive `'FOR UPDATE'` locks.
- **22 Executed Real-PG Integration Tests**:
  - 15 original callbacks preserved verbatim.
  - 2 concurrent reader callbacks with 1500ms `Promise.race` deadline, exact DTO assertions, and safe promise settlement.
  - 5 negative principal authorization callbacks (`outsider`, `expired_session`, `deleted_session` with explicit DB delete, `banned`, `no_onboarding`).
- **Native14 Status**: Both screen captures succeeded (10492ms / 15733ms), but 1 viewer tab vs expected 2 after ticker room-lock timeout; no native acceptance claimed.
