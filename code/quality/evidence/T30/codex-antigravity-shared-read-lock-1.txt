### 3. Integration Regression Tests Added

1. **Concurrent Shared Readers & Exclusive Writer Isolation (Test 13)**:
   - Seeds 2 distinct members in the same call room.
   - Client 1 sends screen `addTrack`, acquiring `FOR SHARE` and stalling on a controlled fake SFU `GetParticipant` barrier.
   - Client 2 sends a `ping` in the same room; its `processBatch` acquires `FOR SHARE` concurrently and completes ping/PONG **before** Client 1's barrier is released.
   - Concurrently, an external writer attempts `SELECT id FROM rooms WHERE id=$1 FOR UPDATE` and is proven blocked via `pg_blocking_pids`.
   - Releasing the barrier lets Client 1 commit, which unblocks the external writer to complete.
2. **Writer `FOR UPDATE` Blocks Runtime Forwarding & Enforces Committed Mutation (Test 14)**:
   - External writer acquires `SELECT id FROM rooms WHERE id=$1 FOR UPDATE`.
   - Client sends screen `addTrack`; runtime `processBatch` is proven blocked on the writer via `pg_blocking_pids`.
   - Under lock, the external writer deletes `call_publish_slots` and commits.
   - Gateway unblocks, freshly checks permissions, and denies `addTrack` with `RequestResponse_Reason.NOT_ALLOWED` (`'Current screen quota required'`), never forwarding to upstream SFU.
