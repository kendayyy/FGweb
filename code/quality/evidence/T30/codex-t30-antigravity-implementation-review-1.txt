### 1. Refined Proposals Overview

1. **[`apps/web/src/features/calls/media.ts`](file:///E:/FGweb/code/quality/evidence/T30/antigravity-implementation-review-1/apps/web/src/features/calls/media.ts)**
   - **SFU Permission Awaiting (Finding 1)**: `awaitScreenPublishPermission(timeoutMs = 5000)` checks `room.localParticipant.permissions` snapshot (matching proto source ID `3` for `Track.Source.ScreenShare`). If not yet updated, listens to `RoomEvent.ParticipantPermissionsChanged` with bounded timeout and abort/disconnect cleanup before calling `publishTrack`.
   - **Optional System Audio (Finding 2)**: `publishScreenTracks(videoTrack, audioTrack)` captures and publishes system audio as `Track.Source.ScreenShareAudio` with `AudioPresets.music` when present and permitted. Local preview is muted. If audio publication fails, rolls back the video track atomically, stops tracks, and releases quota once.
   - **Local Publisher Preview (Finding 3)**: Includes local screen share in `getScreenPublishers()` with `{ identity: localParticipant.identity, trackSid: 'local-screen', isLocal: true }`. Attaching local preview uses local track without remote subscription or second room.
   - **Strict Remote Filtering (Finding 5)**: Enforces `pub.kind === Track.Kind.Video && (pub.source === Track.Source.ScreenShare || pub.source === 'screen_share')`, strictly excluding camera streams.
   - **Idempotent Attachment (Finding 5)**: `attachVideoTrack` checks `attachedTrackSid === sid` and container presence to prevent duplicate `<video>` elements. Stale obsolete subscriptions are explicitly unsubscribed via `pub.setSubscribed(false)`.
   - **Permission Revoke & Unpublish Mapping (Finding 6)**: Maps `LocalTrackPublication` properly and listens to `RoomEvent.ParticipantPermissionsChanged` to revoke local sharing if server revokes permission. Explicit `stopSharing` prevents recursive double-release.
   - **Audio Independence**: Auto-subscribed remote microphone audio on `audioRoot` remains completely isolated and untouched across screen share transitions.
