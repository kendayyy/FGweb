### 1. Proposed Source Files

1. **[`apps/web/src/features/live/LiveViewer.tsx`](file:///E:/FGweb/code/quality/evidence/T30/antigravity-implementation-1/apps/web/src/features/live/LiveViewer.tsx)**
   - **Capture-First Flow**: Synchronous `navigator.mediaDevices.getDisplayMedia({ video: { width: 1280, height: 720, frameRate: 30 } })` execution within the click handler tick before any `await` to maintain transient user activation.
   - **Strict Quota & Slot Boundaries**:
     - Denied/cancelled capture (`NotAllowedError`) dispatches zero claim and zero release (zero quota leak).
     - Deferred capture unmounting before user resolution stops acquired tracks with zero claim and zero release.
     - 409 `CAPACITY_FULL` stops acquired track, dispatches zero release, and presents the 3-slot capacity alert (*"Đã có 3 người chia sẻ màn hình. Giới hạn tối đa là 3 luồng chia sẻ đồng thời trong một nhóm gọi."*).
     - Late claim after unmount or publish failure after successful claim stops acquired tracks and dispatches release once.
     - Native browser floating stop button (`track.onended`) and moderator stop (`LocalTrackUnpublished`) trigger clean release and reset the button.
   - **Platform Detection**:
     - Mobile browser (`/Android|iPhone|iPad|iPod|Mobile/i`) hides capture button and displays view-only guidance (*"Thiết bị di động chỉ hỗ trợ xem luồng chia sẻ và dùng mic, chưa hỗ trợ phát màn hình trực tiếp."*) while preserving viewing and microphone participation.
     - Unsupported desktop browser (`!getDisplayMedia`) hides capture button and displays guidance (*"Trình duyệt này chưa hỗ trợ phát màn hình trực tiếp."*).
     - Narrow desktop viewports (e.g. 360px) retain capture capabilities.
   - **Accessible Stream Selector**:
     - WAI-ARIA `role="tablist"` labeled `"Danh sách luồng phát"` with `role="tab"` buttons displaying participant names and `aria-selected` status.
     - Exactly 0 `<video>` elements in selector tabs (static metadata only).
     - Full keyboard navigation across tabs via `ArrowRight`, `ArrowLeft`, `Home`, and `End` with focus retention.
   - **Single-Stream Stage**:
     - `role="region"` labeled `"Màn hình đang xem"` containing exactly 1 active `<video>` element when subscribed.
     - Automatic standby fallback message (*"Chưa có luồng chia sẻ màn hình nào trong nhóm gọi."*) when all screen publishers terminate.
