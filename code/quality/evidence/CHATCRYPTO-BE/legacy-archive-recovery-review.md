Actual authenticated owner recovery API/CAS and PostgreSQL retain only the opaque vault; tests assert no code/raw session key occurs in persisted bytes using booleans. Fixture KDF1000 is the existing native test setting only, not a product strength recommendation/configuration. Private keys/code/exported plaintext never go into source logs/evidence or backend. This verifies recovery transport and native client key restore with retained server ciphertext; it does not prove production key custody, DB/object backup restoration, post-cutoff lifecycle, source cleanup, password-reset UI or frontend recovery experience. No original plaintext DB/file is deleted and CHATCRYPTO-BE remains IN_PROGRESS.
