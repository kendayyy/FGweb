# Current-owner legacy implementation review — not a completed migration

The approved ADR requires verified historical cohort and current session/device/membership, canonical original text/image/identifier digest, native SDK ciphertext, roundtrip and object/count parity before reconciliation. Existing relay controllers do not expose the declared legacy routes. The existing commit request lacks image mapping and roundtrip receipts. The normal encrypted upload path intentionally rejects an unreconciled conversation. These are remaining BE implementation gaps, not evidence of migrated data.

Unknown history remains blocked. Do not create a cohort from current membership or accept caller-provided verification. An explicit operator-reviewed cohort must have real membership records and source entitlement; fixture records only prove behavior on isolated historical data. Any main historical reconciliation requires its own actual evidence and authorization.

Source identity must bind message ID, original sender/time/client ID/type/reply/mentions and sorted original attachment IDs plus physical source digests/metadata. Reading source images must use the exact owned legacy storage root, reject symlink/path substitution, and recheck source identity and authorization after I/O. Normal private history/image/Socket paths stay closed throughout migration.

Native client migration must preserve original authorship metadata while distinguishing the actual device/user that encrypted imported content. The client cannot treat a migrated author's plaintext record as a cryptographically authenticated original Megolm sender. Add explicit imported-source bindings under a reviewed shared contract if the encrypting historical cohort member differs from the original author. LIVE bindings remain unchanged.

Prepare and reconcile are separate states. A prepared ciphertext or caller boolean is insufficient. Recipient attestations must bind canonical source digest, ciphertext digest, source image digests, conversation/cohort/revision and registered immutable device identities using the existing mature Matrix signed-JSON implementation. Label these as client attestations, not a server proof of decryption. Native acceptance must actually relay Olm keys to the original cohort, decrypt Megolm and encrypted image bytes, compare exact source parity, reject tampering and verify access after join/revoke/conflict.

Retain recoverable encrypted source artifacts outside plaintext production paths through parity/security review. Candidate/source mapping must preserve original IDs/times/cursors without reusing a LIVE session or inventing old membership. Reconciliation and cutoff are atomic per conversation only after all prepared counts, digest/object parity and entitled-recipient roundtrips match. Rollback stays in maintenance/error mode and never reopens old plaintext to newer members. Do not apply a main migration, delete historical data or declare reconciliation from fixture preparation.

Before implementation, adopt only exact missing contract/test/schema/migration prerequisites under the persisted current-owner scope permission, preserving historical DATA/PASS records and old migrations. Protocol changes require their own contract/native review evidence. The current continuous BE session remains open; no FE/QA successor starts.
