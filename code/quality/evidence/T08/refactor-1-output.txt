#### 4. Manual Browser Discord Login Verification Steps

To perform real browser verification against Discord OAuth:
1. Ensure `DISCORD_CLIENT_ID` and `DISCORD_CLIENT_SECRET` are set in `.env.local` (registered in Discord Developer Portal with Redirect URI `http://localhost:3000/api/auth/callback/discord`).
2. Start PostgreSQL and API service:
   ```bash
   npm run start:dev --workspace @fg/api
   ```
3. Open browser and navigate to `http://localhost:3000/api/auth/sign-in/social?provider=discord`.
4. Complete Discord authorization prompt in browser.
5. Verify browser receives HttpOnly `better-auth.session_token` cookie.
6. Make GET request to `http://localhost:3000/api/v1/me` and confirm payload returns matching `id`, `discordId`, `role`, and `isOnboarded`.
